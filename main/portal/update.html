Updating the watch's software

← Back to the settings

A new version brings the watch new features or fixes faults. Your settings stay as they are.

Before you start

  1. Save the new version file on your phone. It is a single file whose name ends in .bin (for example astronomical_watch.bin); get it from whoever gave you the update. Do this while the phone has internet: the watch's network has none.
  2. Put the watch on its charging cable, or make sure its battery is at least 30 %.

Connect the phone to the watch

  1. On the watch, go to the Settings page (the last one on the right), swipe up to Wi-Fi setup and tap the top button. The watch shows a network name and a password. Swipe up once more: a large QR code appears.
  2. Point the phone's camera at the code on the watch and tap the network it offers. If the camera offers none, open the phone's Wi-Fi settings, choose the network name the watch shows and type the password.
  3. The watch's settings page opens by itself in a small window. This window cannot choose files; do this for your phone:

Android

  • Tap the three dots (⋮) in the top right corner of the window.
  • Tap Use this network as is.
  • Open Chrome or Firefox.

iPhone, iPad

  • Tap Cancel in the top right corner of the window.
  • When asked, choose Use Without Internet.
  • Open Safari.
  1. In the address bar at the top of the browser, type exactly: 192.168.4.1/update — this page opens again.

Without these steps the phone does not use the watch's network, which has no internet, and the page does not open.

Install

  1. Tap the file button below and choose the file you saved in step 1.
  2. Tap Install and wait. It counts up to 100 %; this takes about half a minute. Keep the phone near the watch meanwhile and do not lock its screen.
  1. The watch restarts by itself and its network closes; your phone returns to its usual network. That is all. The new version is shown in the last part of the watch's information page (About).

If something goes wrong

If the new version does not start, the watch goes back to the old one by itself; nothing is lost. You can try again. If the problem stays, download the two files below and send them to whoever gave you the update.
